# Atelier — OpenSwarm parity backlog

Scanned from the installed OpenSwarm app (2026-07-01): 54 features, ranked. OpenSwarm's canvas is a DOM world-container (CSS translate+scale) with absolutely-positioned cards — the same model Atelier uses.

**Built so far:** modular core (`window.Atelier`), pan/zoom, drag+resize cards, wheel-zoom, dock app-cards, customizable widgets (double-click → Metric/Status/Chart/Checklist/Clock, persisted), ⌘K command palette, themes (Clay/Slate/Forest) + layout persistence.

## Status legend (2026-07-02, as of round 13)

- **DONE (rN)** — shipped in round N in Atelier's idiom (r1-8 = the early rounds through commit `1651ad6`; rounds 9-13 are itemized in `RESUME.md`).
- **PARTIAL — what remains** — the named part shipped (round given); the remainder is scheduled or explicitly listed.
- **PLANNED (rN)** — not built yet, targeted at the named round.

**2026-07-02 (r17): all 54 rows are DONE or REWORKED — zero PARTIAL/PLANNED rows remain.** Phase B living widgets (Job timer ring, Runs ticker, Campaign gates, Agent orbs, Claude Code burn, Heartbeat) shipped the same round.
- **REWORKED — equivalent** — the OpenSwarm feature as scanned is commercial-clone plumbing or wrong for Atelier; the entry names the shipped Atelier-native equivalent that covers the need, or declines it with the rationale and what covers it instead. No row is a bare skip.
