# Golden Tasks — Atelier's telemetry stand-in

Real recurring jobs Jason produces by hand elsewhere. These ARE the usage signal: every round, before proposing a feature, replay one of these through the CURRENT installed app end to end (drive the running Electron app + in-app agents as a real user would), log the biggest friction to `FRICTION_LEDGER.md`, and build whatever removes it. A feature is NOT done until the agent has USED it, inside the running app, to complete a real slice of a Golden Task, and has captured the actual output artifact as evidence. "Renders / tests pass" is necessary but never sufficient.

Two telemetry-free numbers to move each round: (a) **end-to-end completion rate** = % of Golden Tasks Atelier carries start→finish WITHOUT the agent dropping to raw CLI/tools; (b) **friction per task** = steps/time to complete. Rotate tasks so none monopolizes attention. Re-derive this list from Jason's live vault/MEMORY during each whole-app-critique round.

Steps map to the hero workflow: **R** research · **M** make · **P** publish · **W** watch-and-steer.

1. **Cited research report** [R,M] — Research a topic in the live embedded browser + web search, then produce a well-structured report with real, checkable citations. Artifact: a `.md`/PDF report with sources that resolve. (Jason does this for Algoverse / Trade equity research.)

2. **Source → make → post content loop** [R,M,P] — From a source (a trend, a story, a note), research it, produce a short-form piece, and POST it to a channel. Artifact: the produced media + proof it was actually submitted/posted. THIS is the hero workflow; the publish step is the current gap. (Funny Tech Channel, reddit-shorts, Content pipeline.)

3. **Client website, built + shown** [R,M] — Research a local business, generate a small site, screenshot it rendered. Artifact: the built site + a real screenshot. (agency-websites, ohio-websites, happy-feet.)

4. **Outreach email drafted + sent** [R,M,P] — Research a recipient/business, draft a personalized outreach email, and actually send it (or create a real draft in the mail client). Artifact: the sent/draft message with real recipient + body. (Digital marketing agency outreach.)

5. **Browser research → extracted findings** [R] — Point an agent at a real site/topic, have it read the page and extract structured findings back into a note/document card. Artifact: the read-back page content in a card (proves ReadPage, not just navigation).

6. **Reddit story → vertical short** [R,M] — Take a Reddit story, render a captioned vertical video. Artifact: the rendered `.mp4`. (reddit-shorts pipeline at `~/Content/reddit-shorts` — LATER: bundle it into the app.)

7. **Vault note → knowledge graph** [M,W] — Turn a set of notes into a linked graph view on the canvas. Artifact: the graph rendered from real vault data. (graphify; the vault graph view already exists — use it.)

8. **Scheduled deliverable, unattended** [M,P,W] — Set a Loop to run a deliverable on a schedule and confirm the fired run produced a real artifact while Jason was away, watchable after the fact. Artifact: the job's live chat card + the deliverable it produced.
